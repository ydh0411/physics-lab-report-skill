# Measurement of Resistance by Ammeter-Voltmeter Method

## Aliases

- Measurement of Resistance by Ammeter-Voltmeter Method

## Use This Card When

The report measures small and large resistors with ammeter-outside and
ammeter-inside circuits, including corrected resistance and uncertainty.

## Required Data Tables

- Data Table 1-1: voltmeter and ammeter ranges, internal resistance, accuracy
  class, instrument error, reading error.
- Data Table 1-2: small resistor, ammeter-outside method.
- Data Table 1-3: small resistor, ammeter-inside method.
- Data Table 1-4: large resistor, ammeter-outside method.
- Data Table 1-5: large resistor, ammeter-inside method.
- Optional older tables: diode normal and reverse resistance.

## Formula Checklist

- Approximate resistance: `R = V / I`.
- Ammeter-outside correction: subtract the voltmeter branch current before
  computing the unknown resistance.
- Ammeter-inside correction: subtract the ammeter internal resistance from the
  apparent resistance.
- Instrument error: accuracy class times selected range.
- Relative error: compare measured/corrected values with accepted resistance.
- Uncertainty: propagate current and voltage uncertainties for the selected
  sample calculation.

## Report Pattern

- Abstract: state both circuit arrangements and the conclusion about which
  arrangement is better for small/large resistance.
- Calculations: show one instrument-error sample first, then one full corrected
  resistance and uncertainty example.
- Conclusions: emphasize systematic error from meter internal resistance.
- Questions: explain circuit choice, correction direction, and why accepted
  values may fall outside uncertainty intervals when systematic error remains.

## Common Pitfalls

- Mixing mA and A in `R = V/I`.
- Reporting only approximate `V/I` instead of corrected resistance.
- Using the wrong meter internal resistance for the selected range.
- Treating old senior point values as current template rules.
