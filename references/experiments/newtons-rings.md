# Newton's Rings

## Aliases

- Newton's Rings
- Newton Rings
- 牛顿环
- Lab 3 current label, Experiment 6 historical label

## Use This Card When

The report studies thin-film interference and uses selected dark-ring diameters
to measure the radius of curvature of a plano-convex lens.

## Required Data Table

- Data Table 6-1: dark ring orders, left and right microscope readings,
  diameters, squared diameters, paired differences, and final radius.

## Formula Checklist

- Thin-film thickness: `t approximately r^2 / (2R)`.
- Reflected dark rings: `r_m^2 = m lambda R`.
- Diameter relation: `D_m^2 - D_n^2 = 4 (m-n) R lambda`.
- Radius result from several ring pairs; average paired values when available.
- Uncertainty should include variation among paired differences and microscope
  reading/instrument uncertainty when required by the template.

## Report Pattern

- Prelab: explain concentric rings, wave nature, phase reversal, and why
  monochromatic light is used.
- Postlab: data table first is acceptable; then show radius formula and one
  complete calculation.
- Conclusions: state whether the measured radius is reasonable and discuss ring
  sharpness, tangent reading, dust, and central-contact quality.

## Common Pitfalls

- Using radius readings when the table records diameters.
- Forgetting the factor of 4 in the diameter formula.
- Assuming ring spacing is uniform.
- Treating white-light colored rings as suitable for accurate measurement.
