## Use This Card When

The report measures voltage, period, frequency, and frequency ratios using
time-base mode and X-Y/Lissajous mode.

## Required Data Tables

- Data Table 3-1: peak-to-peak voltage and period of a sine wave.
  Include vertical sensitivity, height, horizontal sensitivity, length, units,
  `V_pp`, period, and frequency.
- Data Table 3-2: known frequency and Lissajous patterns. Include tangent point
  counts or ratio rows and calculated unknown frequencies.

## Formula Checklist

- `V_pp = vertical sensitivity × height`.
- `T = horizontal sensitivity × length`.
- `f = 1 / T`.
- Lissajous frequency relation from tangent counts or pattern ratio. State which
  channel is known and which is unknown.

## Report Pattern

- Abstract: mention time-domain waveform measurement and Lissajous frequency
  determination.
- Calculations: show voltage, period/frequency, and one Lissajous example.
- Comments: discuss trace thickness, calibration drift, pattern stability, and
  reading uncertainty.
- Appendix: attach the completed signed data sheet if required.

## Common Pitfalls

- Forgetting units for sensitivity values.
- Reversing the Lissajous ratio.
- Connecting plotted data points when the figure should show only pattern or
  calculated values.
- Treating unstable patterns as exact measurements.
