## Required Data Tables

- Data Table 1-1: mirror position `d` for fringe counts `N = 0, 50, ... 250`,
  differences over 150 fringes, averaged displacement, and laser wavelength.
- Data Table 1-2: pressure readings `p1`, `p2`, pressure differences, mean
  pressure difference, room temperature, atmospheric pressure, tube length, and
  refractive index of air.

## Formula Checklist

- Laser wavelength: `lambda = 2 Delta d / Delta m`.
- Air index relation from pressure-change fringe count; use the teacher
  calculation template for exact constants.
- Compute relative error against accepted He-Ne wavelength when required.
- For wavelength uncertainty, propagate uncertainty of averaged displacement.

## Common Pitfalls

- Confusing mirror displacement with optical path difference.
- Mixing MPa and Pa in air-index calculation.
- Using `m` fringe count inconsistently between wavelength and air-index parts.
