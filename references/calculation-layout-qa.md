# 计算、排版与检查

本文件覆盖流程的第 ④、⑦ 阶段：计算链、数据表、字体与原生公式、版式、PDF 导出检查。流程位置与四种任务模式见 [references/course-workflow.md](course-workflow.md)；表达要求见 [references/writing-policy.md](writing-policy.md)；模板结构见 [references/course-profile.md](course-profile.md)。

## 1. 数据来源与版本识别

开始计算前先确认自己在用哪一份数据：

- 原始记录、后续确认的录入修订、计算结果三者分开识别。同一实验可能存在多个文件名相近的数据版本（`Data tables_lab7_completed(1).docx` 与后来新提供的数据），以用户本次指定或确认的为准。
- 旧制作脚本里的常量可能含已替换的数据，旧脚本不是数据真源；旧预览稿、无边框试稿也不是提交版。
- 原始记录不因偏离理论值而调整。可以纠正有依据的录入或计算错误，但要保留原始记录，并把改动了哪几项、依据是什么告诉用户（例如原始表将 `nA` 误记为 `s` 时，按实验物理量修正并在交付说明中列出）。
- 仪器量程不足或未能测到某设定点（如电压源达不到 `-2.0 V`）时，在对应表注或正文如实说明原因，不留无解释空白，更不补造数据。
- 无法唯一判断的读数不猜改：列出来问用户，或按「缺失材料」只留空。
- 用户在报告中曾写错的参考值（理论值、常数、单位）也要核对来源，不按记忆沿用。

## 2. 先读教师的公式与表格

写作前打开当次教师提供的对应文件（典型命名 `Calculations for Lab-*.docx`、`Data tables*.docx`），逐项核对：

- 公式的分子、分母、根号范围、幂次、常数取值。
- 符号含义与本课程用法（同一个字母在不同实验可能指不同量）。
- 计算顺序与分组方式：教师分几步算、先算哪一项，保持这个结构。
- 表格的列、表头单位、合并单元格关系、行数分组。

教师文件本身可能有漏项或笔误。发现时按物理含义与教材核实后纠正，并简要告知用户；不机械复制错误，也不擅自换成另一套处理方法。公式排版可以改清楚，处理逻辑不能换。

## 3. 计算链四步

需要展示的计算按以下顺序写，缺一步都不算可复核：

1. **量与公式**：写出符号定义和所用公式，沿用教师的符号与计算项。
2. **数值代入**：带单位代入。大量同类数据可以展示首项与末项、中间用省略号，但要求的全部结果必须保留。
3. **结果**：给出数值与单位。表内统一单位放表头，不能让读者猜角度、长度、压力、波长或时间的单位。
4. **不确定度/相对误差/拟合**：给出公式、实际输入与结果。只写软件输出（如「拟合得到」）不够。

约定：

- 中间计算保留保护位（比最终多 1–2 位），最后按课程规则一次取位；不确定度与主值末位对齐。
- 角度的度/分/秒转换、仪器分度与读数位数、组合量单位都要核对。
- 不是整张表统一设同样小数位：每个量按自身精度取位。
- 参考值要写明数值与单位，并写清比较方式（相对误差、是否落在不确定度范围内）。超出范围也照实写实际结果。

## 4. 数据表

- 列、表头单位、合并关系保留教师文件的设定。
- 行数按当次教师要求调整：多余的未测组整组删除，不把通用模板行数当成本次必须测量的组数（例如 Lab9 只测 5 组油滴，就删掉第 6–10 组空白行）。
- 正文与附录中凡是能由已有记录算出的派生栏（平均值、差值、平方、相对误差等）都要补全，不能因原始记录当时没算就让成稿留空。
- 未知实测值仍留空，不补造；空栏与未测组要能一眼看出区别。
- 补填优先用可编辑原生表格（Word 表格），保留源记录文件；核对测量值、有效数字与正文一致。
- 表格避免跨页拆开同一组测量；列宽按内容调整，允许为可读性改行高与断页位置。

## 5. 字体与公式

| 元素 | 约定 |
|---|---|
| 英文正文 | Times New Roman，通常 12 pt |
| 公式中的拉丁字母与数字 | Times New Roman，通常 12 pt，不默认 Cambria Math |
| 中文姓名、教师等封面信息 | 宋体 / SimSun（缺汉字的 TNR 会显示为方块或替换字形） |
| 封面个人信息 | 通常 15 pt |
| 封面实验标题 | 通常 14 pt；换行合理，保留官方大标题样式 |
| 封面标签 | 通常 12 pt；沿用模板位置 |
| 表格 | 约 10–11 pt 或既有清晰字号，不为统一 12 pt 挤出单元格 |
| 页眉页脚与次要文字 | 沿用模板或已核对的现有字号，不机械放大 |

公式结构与 OMML Times New Roman 实操：

- 用原生可编辑 OMML，不把公式批量做成截图来掩盖字体问题。
- 物理变量斜体，数字、单位、数学函数、运算符、描述性下标正体；上下标、分式、根号、平均值横线结构正确。
- **避免 Cambria Math 回退的已验证 XML 写法**（已通过 Lab7–10 PDF 实测）：在 `<m:r>` 内同时设置 `<m:rPr><m:nor/><m:sty m:val="i|p"/></m:rPr>` 与 `<w:rPr><w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman" w:eastAsia="SimSun" w:cs="Times New Roman"/>...<w:i w:val="1|0"/></w:rPr>`，把数学字符标为普通文本格式并显式锁定 Times New Roman。
- **LibreOffice 渲染斜体兼容**：LibreOffice 会忽略 `<m:nor/>` 数学 run 上的 `<w:i/>`。用 LibreOffice 做版式预览时，可用临时副本仅移除变量/斜体 run 的 `<m:nor/>` 以检查断行与斜体；正式交付以 Word「另存为 PDF」导出主文件为准，不把临时渲染文件当提交版。
- 伸缩括号、根号等符号可用真实符号字体；这不等于允许拉丁公式字母回退到 Cambria。

字体陷阱（这两条都实测过）：

1. **DOCX 里写了字体名，PDF 里不一定用了它。** Word 默认把未加 `<m:nor/>` 的数学字母替换成 Cambria Math（早期 Lab6 报告因此失败）；LibreOffice 则默认把 Microsoft 核心字体替换成度量兼容字体（Times New Roman → Liberation Serif、Calibri → Carlito、Cambria → Caladea）。
2. **导出 PDF 后必须查实际字体**，不能只检查 DOCX 的样式 XML。已确认的对照：同一台机器上，Word「另存为 PDF」且按上述 OMML 锁定的正式报告字体为 `TimesNewRomanPSMT` / `TimesNewRomanPS-ItalicMT` / `SimSun`（检查通过）；LibreOffice 导出的同一份模板为 `LiberationSerif` / `LinuxLibertineG` / `Carlito`（检查失败，不能作为提交版）。

因此：

- 最终 PDF 用 Word「另存为 PDF」导出并嵌入字体；LibreOffice 只用于看版式或快速预览。
- 检查命令见第 9 节；Cambria Math 与 LibreOffice 替换字体会被分别报出来，处理方式不同。

## 6. 版式

保留模板原生要素，不重新设计：

- A4 纵向、封面与正文分节、原生边框、logo、水印、评分框、页码域、页眉页脚。
- 正文页码按模板从 1 开始，不能用手打数字替代页码域。
- 段标题与其后首段同页；公式不被拆开；分式、角分符号、下标不被裁切；评分框下方留出正文空间。
- 正文按内容连续排放，相邻计算在空间允许时同页；避免每项计算单独一页造成大块留白，也不为凑页数删内容或缩成难读小字。
- 封面保留模板固有留白；封面信息与页眉信息（学号、邮箱、日期）要一致。
- 与对应实验的学长报告比较版面密度和组织，再检查实际渲染页，不只检查代码或 XML。

## 7. 数值规则

课程规则的查找顺序：当次教师计算文件与明确要求 → 本课程数据处理规范/教材 → 一般规则。若课程规则没查到，不把某个通用取位口诀写成「课程要求」；规则本身也不在报告里解释（除非题目要求）。

- **A 类不确定度**（有重复测量）：均值 → 样本标准差 → 均值的标准不确定度。
- **B 类不确定度**（仪器与读数限制）：课程模板若用矩形分布，除以 `√3`。
- **合成**：相互独立的分量平方和开根号，`σ = sqrt(σ_A² + σ_B² + …)`。
- **乘积与商**：用相对不确定度传播；幂次要把相对不确定度乘以幂的绝对值，例如直径平方贡献 `2σ_d/d`。
- **有效数字**：主值与不确定度末位对齐；不确定度按课程规则取 1–2 位；中间量保留保护位。
- **参考值比较**：写参考值、单位与比较结果；同时给出相对误差和是否在不确定度范围内。
- **回归与作图**：
  - 只用真实数据数组；散点加拟合线，不用折线连接测量点冒充趋势；多条 `I-V` 测量曲线（如 Franck-Hertz、光电效应）需要展示曲线走势时，用不同标记符号和颜色/线型区分，并在图注注明 `lines connect measured points`。
  - 轴标签写物理量与单位；拟合图在图注或正文给出拟合式、斜率/截距与拟合质量（`R²` 或 `r`）；峰位读取图在对应峰顶标注序号。
  - 生成图优先矢量 PDF 或高分辨率（≥300 dpi）PNG 嵌入 Word；绘图脚本随工作工程保存，路径用相对路径。
  - 需要论证线性关系时，可同时给出「原始量对原始量」和「线性化后」两种图（如 I 对 cos²θ）。
- **缺失数据**：用户允许时留空，先完成原理、表格与符号推导；不拿示例数据当实测，也不在摘要里声称已有一致性结论。预习题给定的数据属于题目输入，可以正常计算。

## 8. 导出与交付

1. 用 Word 打开定稿 DOCX，确认没有修订痕迹、批注、域未更新、图片错位。
2. 「另存为 PDF」并嵌入字体；不要用截图拼接。
3. 逐页看 PDF：封面信息与正文信息、边框、水印、评分框、段落与表格断页、公式符号、签名位置、页码、是否出现意外空白页。
4. 字体清单与页面检查配合使用：字体对但版面断开仍要改；版面正常但字体回退仍要重导。
5. 中间产物（渲染图、预览 PDF、临时转换结果）放工作区已有的 `build/`、`cache/` 一类目录，不与提交版混放；不额外打包未经请求的清单或校验和。

签名：按用户授权沿用已有签名图时，放在数据附录末尾右下角，大小清晰适中、可略放大但不覆盖文字，不整页铺图。prelab 不自动加签名。原始数据扫描图保持清晰、方向正确，放在对应附录。

## 9. 检查命令与判定

```bash
python3 scripts/check_docx.py 报告.docx            # 字体统计、非 TNR/宋体的 run、OMML 数、节标题、评分框、页边距
bash  scripts/docx_to_pdf.sh 报告.docx 报告.pdf    # LibreOffice 导出，仅用于看版式
bash  scripts/check_pdf_fonts.sh 报告.pdf          # PDF 实际字体（正式提交版）
```

判定口径：

| 现象 | 含义 | 处理 |
|---|---|---|
| `check_pdf_fonts.sh` 报 Liberation/Carlito/Caladea | LibreOffice 默认替换字体 | 改用 Word「另存为 PDF」重导 |
| 报 Cambria Math | 公式字体被 Word 替换 | 在 Word 中把公式字体设回 Times New Roman，重导 |
| 报 `SimSun` 缺字或中文显示异常 | 字体未安装或字形缺失 | 安装宋体，重新导出 |
| 报「未检测到任何字体」 | 整份 PDF 可能是扫描图片 | 确认正文不是图片替代 |
| `check_docx.py` 非 TNR run 命中 | 正文/表格里混入其他字体 | 按命中位置改回 TNR（模板残留的历史 run 先确认是否保留） |
| 评分框数、节标题不符 | 改动了模板结构 | 回到模板副本重修，不手改评分框 |

`check_pdf_fonts.sh` 白名单：Times New Roman、SimSun/宋体、Symbol/OpenSymbol（项目符号）、TeX Gyre 回退；Base-14 的 `Times-Roman` 视为可用但提示未嵌入。缺 `pdffonts`（poppler）时脚本退出码 3，此时用 PDF 阅读器的字体面板人工核对并说明。

## 10. 分级检查

| 任务类型 | 检查范围 |
|---|---|
| 新建或重算 | 逐题对照本次问题；公式、代入、单位、取位、各处结果一致性；与对应学长报告核对覆盖情况 |
| 纯字体/排版修改 | 先记录正文、表格数值、公式表达式、图片、日期、签名；改后逐一对比，确保内容未变。不借此重算或换用旧数据 |
| 只读提交检查 | 给出问题清单与位置，不直接改稿；说明哪些检查没做（未渲染、未核对数据等） |
| 更换模板 | 内容完整迁移到最新对应类型模板；逐项确认问题、计算、表格、图像、页眉身份与签名；没有明确删除请求，不清理其他模板 |

字体检查不能替代数值检查；XML 合法也不能证明页面合格。做了哪一项就说哪一项，没做就说没做。
